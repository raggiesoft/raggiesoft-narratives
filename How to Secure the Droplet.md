### How to Secure the Droplet

To transition from the temporary self-signed certificate to a permanent HTTPS setup, you will swap out the dummy files with real ones from your Cloudflare dashboard:

**1. Generate the Origin Certificate**

- Log into your Cloudflare dashboard and select `raggiesoft.com`.
    
- Navigate to **SSL/TLS** > **Origin Server**.
    
- Click **Create Certificate**.
    
- Leave the default settings and choose a long expiration date (Cloudflare allows these to last up to 15 years, meaning zero maintenance for you).
    
- Once generated, Cloudflare will display two blocks of text: the **Origin Certificate** and the **Private Key**. Keep this window open.
    

**2. Replace the Temporary Files** SSH into your new DigitalOcean droplet and replace the temporary files that were generated by the `openssl` command in your Cloud Init script.

Open the `.pem` file and paste in the **Origin Certificate** text:

Bash

```
sudo nano /etc/nginx/ssl/raggiesoft.pem
```

Open the `.key` file and paste in the **Private Key** text:

Bash

```
sudo nano /etc/nginx/ssl/raggiesoft.key
```

**3. Restart Nginx** Apply the new long-term certificates by restarting the web server:

Bash

```
sudo systemctl restart nginx
```

Because the Origin Certificate is trusted implicitly by Cloudflare's proxy, your site will now serve secure, valid HTTPS to the public without requiring an automated renewal script running in the background.
